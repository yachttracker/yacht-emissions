# Sicherheit

Dieses Repository gehört zu einer Masterarbeit (öffentliches Emissions-Dashboard für Superyachten).

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue, sondern vertraulich über
GitHub: Tab „Security“ → „Report a vulnerability“.

Zugangsdaten (API-Keys, Datenbank-URLs) gehören nie ins Repository, sondern in die
Service-Variablen auf Railway bzw. in eine lokale `.env` (siehe `.env.example`).
